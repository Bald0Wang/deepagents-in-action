# ch03 答疑知识库 · 虚拟文件系统

## 核心概念

**虚拟文件系统（VFS）**是 Deep Agents 的上下文工程核心：Agent 通过一组文件工具读写「文件」，而文件实际落在哪种存储由 **Backend** 决定。换后端不改变 Agent 的工具用法。

**七种内置文件工具**：`ls` / `read_file` / `write_file` / `edit_file` / `delete_file`（部分版本）/ `glob` / `grep`。它们由 `FilesystemMiddleware` 注入。

**五种存储后端**：
| 后端 | 特性 | 换 thread 后 |
|---|---|---|
| `StateBackend` | 临时，存在图的 state 里 | 文件消失 |
| `FilesystemBackend` | 本地磁盘 + `virtual_mode` 路径沙箱 | 文件在磁盘上，仍在 |
| `LocalShellBackend` | 继承 FilesystemBackend，额外提供 `execute` | 同上 |
| `StoreBackend` | 跨线程持久（LangGraph Store + namespace 隔离） | 仍在（跨线程） |
| `CompositeBackend` | 按路径前缀路由到不同后端 | 取决于路由 |

## 关键代码事实

- `FilesystemBackend(root_dir=str(ROOT), virtual_mode=True)`：`virtual_mode` 把 root_dir 当虚拟根，`/workspace/x` 映射到 `ROOT/workspace/x`，并拒绝 `..` 穿越。
- `StateBackend` 的 `files` 会出现在 `result["files"]`，值是 dict（含 `content`/`encoding`/`modified_at`），取值要 `meta["content"]`。
- `StoreBackend(namespace=lambda rt: (...))`：namespace 按用户隔离；本地 invoke 时 `rt.server_info` 为 None，用 `getattr(rt.context, "user_id", "local-user")` 兜底。
- `CompositeBackend(default=StateBackend(), routes={"/memories/": StoreBackend(...)})`：`/memories/` 走 Store，其余走 State。**注意 store 里的 key 会剥掉路由前缀**（`/memories/pref.txt` → `/pref.txt`）。
- `LocalShellBackend(root_dir=..., virtual_mode=True, inherit_env=False)`：`execute` 执行 Shell；`inherit_env=False` 只保留最小 PATH/HOME。

## 权限控制

- **声明式**：`FilesystemPermission(operations=["write"], paths=["/policies/**"], mode="deny")`，传给 `create_deep_agent(permissions=[...])`。
- `mode` 取值：`"allow"` / `"deny"`（工具返回权限错误）/ `"interrupt"`（暂停等人工审批，需 checkpointer）。
- 规则按声明顺序匹配，**首个命中生效**。

## 自定义后端三种写法

1. **继承**：`class GuardedBackend(FilesystemBackend)`，重写 `write`/`edit` 拦截敏感前缀。
2. **包装**：`class PolicyWrapper(BackendProtocol)`，持有 `inner`，只拦 `write`/`edit`，其余方法透传——适用于任何后端。
3. **从头实现**：实现 `BackendProtocol` 六个方法 `ls/read/write/edit/grep/glob`，用内存 dict 模拟 S3。

## 上下文自动管理

- `SummarizationMiddleware(model=..., backend=StateBackend(), trigger={"messages": 6}, keep=("messages", 2))`：消息数超过阈值触发总结；完整历史存档到 backend（`/conversation_history/`）。
- 总结后任务清单（`todos`）仍然完整——这是「北极星」论断。

## 易错点

- `virtual_mode` 只约束**文件工具**，不限制 Shell 的绝对路径（`LocalShellBackend` 的 Shell 仍能访问宿主 FS）。
- `StoreBackend` 需要 `store=` 参数或运行在 LangGraph 执行上下文中。
- `CompositeBackend` 的 `routes` 前缀要以 `/` 开头、以 `/` 结尾，否则匹配会出问题。
- 自定义后端要实现 `BackendProtocol`，返回值用协议里的 `WriteResult`/`ReadResult`/... 等类型。

## 版本提示

- `virtual_mode` 需要 deepagents ≥ 0.5.0；`FilesystemPermission` 基础权限 ≥ 0.5.2；`interrupt` 模式 ≥ 0.6.8。
