# ch02 答疑知识库 · 快速上手

## 核心概念

**Deep Agents 的最小用法**：`create_deep_agent(model=..., tools=..., system_prompt=...)` 返回一个编译好的 LangGraph 图，用 `agent.invoke({"messages": [...]})` 运行，结果取 `result["messages"][-1].content`。

**三要素**：
1. `model`：一个 LangChain 的 chat model 实例（本课程用 `ChatOpenAI` 接 DeepSeek 官方兼容接口）。
2. `tools`：自定义工具的 Python 函数列表。
3. `system_prompt`：角色与行为指令。

**自定义工具的三要素**（缺一模型就用不好）：
1. **参数类型标注**：`def calculate(expression: str) -> float`——类型标注会转成工具的参数 schema。
2. **docstring**：会成为工具描述，模型据此决定何时调用。
3. **默认值**：可选参数用默认值表达，如 `to_currency: str = "CNY"`。

## 关键代码事实

- 模型接入：`ChatOpenAI(model=os.environ.get("MODEL_NAME", "deepseek-v4-flash"), api_key=os.environ["DEEPSEEK_API_KEY"], base_url="https://api.deepseek.com/v1")`。
- `01_hello_weather.py`：最小 Agent，一个 `get_weather` 工具。
- `02_calculator.py`：两个工具（`calculate` / `convert_currency`），演示「参数类型标注 + docstring + 默认值」。
- `03_research_assistant.py`：Tavily 搜索工具，`TavilyClient(api_key=...)`，工具参数含 `Literal["general","news","finance"]`。
- `03b_research_assistant_ddg.py`：DuckDuckGo 免 Key 版，`DDGS(timeout=20)`，带「后端轮换 + 重试」兜底（auto→bing→brave）。

## 易错点与常见问题

- **工具 docstring 不写**：模型不知道何时调用；`Args:` 段落里的描述会进 schema。
- **`eval` 的安全问题**：`02_calculator.py` 用 `eval` 只是教学简化，生产必须换安全解析库（如 `ast.literal_eval` 或表达式解析器）。
- **`result["messages"][-1].content`**：最后一条是 AI 消息；不要用 `result[-1]`。
- **环境变量**：`MODEL_NAME` 用环境变量管理，别把模型名写死；API Key 走 `.env`，不要提交。
- **DuckDuckGo 超时**：默认 `auto` 后端偶发超时（mojeek 不稳定），代码里用多后端 + 重试兜底。
- **`include_raw_content`**：Tavily 的该参数控制是否返回网页正文，默认 False 以控制上下文体积。

## 版本提示

- 课程要求的 deepagents ≥ 0.5；ch02 实测 0.7.6+。
- ch02 的脚本直接 `uv run --env-file .env 01_hello_weather.py`。
