# ch06 答疑知识库 · 异步子 Agent

## 核心概念

**同步子 Agent（ch05 的 `task`）**：主 Agent 调用后阻塞等待子 Agent 跑完。多个长任务只能串行，用户盯着转圈。

**异步子 Agent（`AsyncSubAgent`）**：主 Agent 调用 `start_async_task` 后**立刻**拿到 `task_id`，任务在后台独立 thread 运行。主对话不阻塞，多个子任务可并行。

## 遥控器工具（AsyncSubAgentMiddleware 注入）

| 工具 | 作用 |
|---|---|
| `start_async_task` | 启动后台任务，立即返回 `task_id` |
| `check_async_task` | 查询某个任务状态（running / success / failed） |
| `update_async_task` | 在原任务上追加指令（不重开任务） |
| `list_async_tasks` | 列出所有后台任务 |

## AsyncSubAgent 定义

```python
AsyncSubAgent(
    name="researcher",
    description="Long-running background research worker. Each run takes ~5 seconds.",
    graph_id="timed_researcher",       # 必须与 langgraph.json 注册名一致
)
```

- 不传 `url` → **ASGI 进程内传输**（同部署）。
- 传 `url="http://127.0.0.1:2025"` → **HTTP 远程传输**（跨服务）。
- 混合拓扑：同一个主 Agent 可同时声明「同部署 + 远程」两种子 Agent。

## 运行前提

异步子 Agent 需要 **LangGraph Server** 部署环境：
```bash
uv run langgraph dev --n-jobs-per-worker 4 --port 2024
```
`langgraph.json` 注册图：
```json
{"graphs": {"supervisor": "./graphs/supervisor.py:graph", "timed_researcher": "./graphs/timed_researcher.py:graph"}}
```

**注意**：`langgraph dev` 下**不要**传 `checkpointer`——平台自带持久化，传了会报错。

## 关键行为规则（写进 system_prompt）

1. 派出任务后立刻把 `task_id` 原样告诉用户并停止，**不要主动轮询**。
2. 用户问进度时才 `check_async_task`；对话历史里的状态永远是过时的。
3. 中途改需求用 `update_async_task`，不要重开任务。

## 计时实验结论

- 同步：3 个 5 秒任务 → 逐个阻塞，约 15 秒。
- 异步：3 个任务并行启动，主线程立即返回；总耗时接近单个任务（需 worker 槽位足够）。

## 易错点

- `graph_id` 与 `langgraph.json` 键名不一致 → `start_async_task` 报找不到 Agent。
- 本地 `create_deep_agent` 直接 invoke 无法验证异步行为，必须起 LangGraph Server。
- 异步任务的状态在对话历史里会过时，汇报进度前必须实时 `check`。
- 本作业的 capstone **不本地运行** ch06 的异步实验（需要 Server 环境），但答疑子 Agent 覆盖其知识。

## 版本提示

- `AsyncSubAgent` 来自 `deepagents`，需要较新版本（课程 ≥ 0.5，ch06 实测 0.7.x）。
