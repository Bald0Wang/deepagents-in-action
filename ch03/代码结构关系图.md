## 2. custom_backends.py —— 三个自定义后端类

### 2.1 类继承 / 实现关系

```mermaid
classDiagram
    class FilesystemBackend {
        <<deepagents.backends>>
        +write()
        +edit()
        +read()
        +ls()
        +grep()
        +glob()
    }
    class BackendProtocol {
        <<Protocol>>
        +ls()
        +read()
        +write()
        +edit()
        +grep()
        +glob()
    }

    class GuardedBackend {
        -deny_prefixes
        -_denied(path)
        +write(file_path, content)
        +edit(file_path, old, new)
    }
    class PolicyWrapper {
        -inner
        -deny_prefixes
        -_deny(path)
        +ls() +read() +grep() +glob()
        +write() +edit()
    }
    class S3Backend {
        -bucket
        -prefix
        -_objects
        -_key(path)
        +ls() +read() +write() +edit() +grep() +glob()
    }

    FilesystemBackend <|-- GuardedBackend
    BackendProtocol <|.. PolicyWrapper
    BackendProtocol <|.. S3Backend
```

### 2.2 GuardedBackend 调用关系

```mermaid
flowchart TD
    w["write(path, content)"] --> d["_denied(path)"]
    e["edit(path, old, new)"] --> d
    d --> hit{"命中 deny_prefixes?"}
    hit -->|"是"| rej["返回 WriteResult(error=...)"]
    hit -->|"否"| sup["super().write/edit 交给父类"]
```

### 2.3 PolicyWrapper 调用关系

```mermaid
flowchart TD
    w["write(path, content)"] --> d["_deny(path)"]
    e["edit(path, old, new)"] --> d
    d --> hit{"命中 deny_prefixes?"}
    hit -->|"是"| rej["返回 error"]
    hit -->|"否"| inner["self.inner.write/edit 透传"]
    ls["ls / read / grep / glob"] --> pass["直接透传 self.inner"]
```

### 2.4 S3Backend 调用关系

```mermaid
flowchart TD
    key["_key(path) = prefix + path"] 
    ls["ls(path)"] --> key
    read["read(path, offset, limit)"] --> key
    write["write(path, content)"] --> key
    edit["edit(path, old, new)"] --> key
    grep["grep(pattern, path, glob)"] --> key
    glob["glob(pattern, path)"] --> key
    key --> obj["self._objects dict<br/>(key -> content)"]
```

## 附：关系图说明

| 图元素 | 含义 |
|---|---|
| `A --> B` 实线箭头 | A 调用 / 依赖 B |
| `A -.-> B` 虚线箭头 | 间接依赖 / 配置注入 |
| `subgraph` | 逻辑分组（模块内 / 函数内） |
| `classDiagram` 空心箭头 `<|..` | 实现协议 |
| `classDiagram` 实心箭头 `<|--` | 继承父类 |
| 菱形 `{...}` | 条件判断 |
